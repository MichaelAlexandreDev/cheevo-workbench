# Notas de estudo

Resumo do que foi feito em cada etapa e subetapa do roadmap, para estudar depois. Escrito em
português de propósito (o resto da documentação do projeto é em inglês).

Cada subetapa segue o mesmo formato:

- **O que foi feito**: o resultado, em poucas linhas.
- **Conceitos**: o que você precisa entender para ler o código.
- **Arquivos para ler**: em ordem, do mais importante para o menos.
- **O que aprendemos com a referência**: o que olhamos em `reference/` e o que decidimos diferente.
- **Problemas encontrados**: erros que apareceram e como foram resolvidos.
- **Para fixar**: perguntas e exercícios curtos. Tente responder sem olhar o código.
